# 恒迪五金 修改报告（2026-10-22 ~ 10-24）

## 1. 工厂账本分为“买的”和“进货的”
- 账本新增 kind：CUSTOMER（买的，应收）、SUPPLIER（进货的，应付）；同名可在两类里各有一本。
- 采购单保存后记账，自动记入对应厂商的“进货的”账本（没有就自动新建）；拿货单、退货单只能记入“买的”。
- 商品页默认显示全部商品，可按源头厂商筛选，并能直达该厂账本和采购单。
- 迁移脚本：`migrations/20261022_factory_ledger_kind.sql`（SPRING_SQL_INIT_MODE=never 时需手动执行）。

## 2. 界面精简
- 按钮整体变小，多按钮选择改为按索引的选择器（picker）。
- 开单页的商品行默认折叠；开单记录、账本页同步压缩，列表优先。

## 3. 拍照开单重做
- 先选单据类型（拿货/退货/采购）再拍照，不再靠关键词猜。
- 识别出错时尽量降级为备注，不再整张失败；有进度弹窗，可取消、重拍。
- 保留原图和每行的位置，开单页可对照原图、点开查看。
- 迁移脚本：`migrations/20261024_attachment_ocr_layout.sql`。

## 4. 原图的保存规则（本次）
- 原图只有在单据记入工厂账本后才算保存。
- 商品详情、账本明细只显示已记账单据的原图；未记账的草稿只在开单页里看。
- 识别失败/取消/重拍、删除草稿、从账本删除单据时，没入账的原图记录被删除，云文件由小程序同步删除。
- 已记账（含已冲销）的单据原图受保护，请求放弃也不会被删。

## 6. 遗留事项
- 保存了但一直没记账、也没删除的草稿，其原图会一直保留；可加定时清理。
- 开单记录按账号隔离，其他账号看不到对方的单据；是否改为全店共享待定。
- 旧的已确认采购单没有补记到进货账本，可做一次性补录。
