# ADR-0002：Excel 匹配采用确定性候选与只读预览

状态：Accepted
日期：2026-09-30

## 背景

买家需求表和厂家价格表的列名、顺序与商品标识经常不同。系统需要自动完成高把握匹配，又不能因为名称相似或同名规格不同而修改错误商品。

## 决策

字段映射、标准化、商品匹配和变更预览使用确定性后端服务。条码精确命中优先；没有条码时，只有名称以及可选规格精确且唯一才自动匹配。其余结果返回候选并等待人工选择。所有结果写入 `excel_task_mapping` 和 `excel_task_row_result`，不写正式业务表。

每次映射请求可以携带任务版本。版本不一致时拒绝覆盖。多工作表任务全部完成映射后才进入 `READY_FOR_REVIEW`。

## 选择理由

- 匹配规则可解释、可复现、可测试。
- 原始值、标准值、候选商品和变更前后值可以逐行追溯。
- 模型以后可以建议映射，但不能越过确定性校验和人工确认直接写库。
- 只读预览可以在正式提交能力开发前安全上线测试。

## 不变量

- 原始单元格和原始行号不得覆盖。
- 歧义匹配不得自动选择第一个候选。
- 预览阶段不得修改商品、库存、价格和订单。
- 正式提交必须另行设计幂等键、权限、版本复核和操作日志。

## 后续

增加人工选择商品候选、逐行排除、整单校验和带幂等键的提交协议。
