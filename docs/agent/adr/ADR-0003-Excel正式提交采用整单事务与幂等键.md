# ADR-0003：Excel 正式提交采用整单事务与幂等键

状态：Accepted
日期：2026-09-30

## 背景

Excel 任务在预览后可能经过多次人工审核，也可能因为网络重试而重复提交。在预览到提交之间，商品价格或库存还可能被其他业务操作修改。直接逐行写入会造成部分成功、重复入库或覆盖较新数据。

## 决策

正式提交采用单个数据库事务。提交请求必须携带任务版本和由客户端生成的幂等键。后端锁定任务记录，完成整单校验，并重新比较预览基线与当前业务数据。任一行失败时整批回滚。

相同操作人、相同幂等键和相同任务的重试返回首次结果。一个任务只允许成功提交一次。正式提交后任务进入 `COMMITTED`。

## 支持范围

- 厂家价格表更新商品进价。
- 商品资料表新增或更新商品。
- 盘点表设置实际库存。
- 到货表增加库存。

买家需求表暂时没有稳定的报价单数据模型，因此只允许审核和预览，不允许写入正式表。

## 不变量

- 待确认行和无效行不能提交。
- 被人工排除的行不得产生业务写入。
- 预览后发生价格或库存变化时必须重新生成预览。
- 商品库存与库存表在同一事务内同步。
- 每次正式提交必须记录真实操作人、提交摘要和库存明细日志。

## 后续

增加买家报价单、行内字段修正、映射模板和厂家价格版本对比后，再扩展新的提交目标。
