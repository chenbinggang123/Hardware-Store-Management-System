# Agent 与文件任务变更记录

## [0.5.0-dev] - 2026-10-01

### Changed（Harness 第一阶段解耦）
- `AgentHarness` 保留有限模型循环、暂停和恢复编排，不再直接执行工具或记录 Trace。
- 新增 `AgentToolExecutor`，统一负责工具查找、策略判断、审批预览和执行。
- 新增 `AgentRunStore`，隔离 Agent 运行记录的创建、保存、读取和审批抢占。

### Changed（Harness 第二阶段解耦）
- 新增 `AgentContextManager`，统一负责会话上下文装配、工具结果恢复、JSON 编解码和重复调用指纹。
- 新增 `AgentApprovalService`，集中管理等待确认、审批抢占、过期、取消、恢复执行和失败收口。
- 新增 `AgentRunResultFactory`，统一生成运行结果和结构化确认卡片。
- `AgentHarness` 缩减为模型循环与组件编排，不再包含审批字段拼装或确认卡片文案分支。
- 确认卡片标题下沉到 `AgentToolDefinition.approvalTitle`；新增工具可自带展示元数据，无需修改结果工厂。

### Fixed
- 审批抢占后若参数损坏或工具风险等级变化，现在会将任务明确收口为失败，不再遗留为无法继续处理的 `RUNNING` 状态。

### Added（扩展点）
- 新增强类型 `PreToolUse`、`PostToolUse`、`ToolError` 生命周期 Hook。
- 原有工具 Trace 改为 Hook 实现；后续审计、指标、脱敏和限流可独立接入，不修改模型循环。

### Compatibility
- 保留 `AgentHarness` 原有测试构造方式和审批语义。
- 已批准工具恢复执行时不重复生成审批预览。

### Evaluation
- Agent 定向回归新增工具执行管线测试，覆盖成功、工具异常、审批预览和后置 Hook 故障隔离。
- 新增审批过期、取消清理、上下文恢复和审批准备失败收口测试。
- 后端全量回归 111 项测试通过。

## [0.4.0-dev] - 2026-09-30

### Added（第三阶段）
- 新增人工选择商品、批准新增商品和逐行排除接口。
- 新增整单校验，集中返回待确认、无效、未映射和任务用途等阻塞原因。
- 新增供应商进价、商品导入、盘点和采购到货的事务化提交。
- 新增幂等提交记录、任务行锁、业务数据漂移检查、库存日志和操作日志。

### Security（第三阶段）
- 正式提交必须同时通过用户隔离、任务版本、整单校验和业务数据一致性检查。
- 任一行失败时整批事务回滚；买家询价和未分类任务仍禁止写正式业务表。

### Database（第三阶段）
- 新增 `excel_task_commit`，每个任务最多一个成功提交记录，每个操作人的幂等键唯一。

### Evaluation（第三阶段）
- 新增人工消歧、进价幂等提交、业务数据漂移、盘点三表同步和新品导入测试。
- 当前全量回归 103 项测试通过；Excel 专项 12 项测试通过。

### Added（第二阶段）
- 新增逐工作表字段映射，支持商品名称、条码、规格、单位、数量、单价、金额、备注和双方 SKU。
- 新增确定性商品匹配：条码精确优先，名称和规格仅在唯一命中时自动匹配，其他情况保留候选供人工复核。
- 新增行级标准化结果、问题清单、动作类型及变更前后值预览接口。
- 新增任务版本校验，阻止旧页面覆盖较新的映射结果。

### Security（第二阶段）
- 映射和预览结果仍只写暂存表，不修改商品价格、库存或订单。
- 多工作表任务只有全部完成映射后才进入 `READY_FOR_REVIEW`。

### Database（第二阶段）
- 新增 `excel_task_mapping` 和 `excel_task_row_result` 两张表，原始行数据保持不变。

### Evaluation（第二阶段）
- 新增条码精确匹配、同名歧义、必填映射、版本冲突和价格不落正式表测试。

### Added
- 新增独立 Excel 文件任务模块，支持 XLS、XLSX、CSV 和 CloudBase 文件来源。
- 新增任务列表、任务详情、工作表信息和原始行分页预览接口。
- 保存原文件标识、SHA-256、工作表、原始行号、原始单元格和审核状态。

### Changed
- Excel 不再只能作为 Agent 提示词附件使用，文件处理拥有独立、可恢复的任务状态。

### Security
- 所有文件任务查询均按 `operatorId` 隔离。
- 上传与解析不会直接修改商品、价格、库存或订单。
- 文件内容只作为不可信业务输入保存，后续写入必须经过映射、影响预览和人工确认。

### Database
- 新增 `excel_task`、`excel_task_sheet` 和 `excel_task_row` 三张表。

### Evaluation
- 新增公式求值、重复表头、原始行号、GB18030 CSV、空文件和用户隔离测试。

### Risks
- 当前默认把第一个非空行作为表头，复杂多层表头需要下一阶段的人工校正能力。
- 当前上限为每个任务 2,000 个非空源行、80 列和 10 MB 文件。

### Rollback
- 停止前端调用 `/excel-tasks` 即可关闭新入口。
- 新表不影响现有 Agent 附件、商品、库存和订单表；回滚代码时可以暂时保留新表。
