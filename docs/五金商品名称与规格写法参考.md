# 五金商品名称与规格写法参考（第一版）

整理日期：2026-10-24。用途：为小五识别进货单提供核对依据，不替代厂商目录、原图或用户确认。本版重点为店内样例涉及的钻头、丝锥、铰刀、磨棒，并补充量具、手工具、气动接头、砂纸。

没有查到一份能覆盖全部五金店手写票据的统一“行规”。以下明确区分：厂家目录可验证的写法、根据本店样例提出的OCR候选、尚需厂商确认的简称。厂家未公开的手写习惯不能冒充国家标准。

## 1. 顿号能否出现在规格里

能出现在规格描述里，但不能直接当作小数点。

- 三丰目录列举同组平晶厚度时使用顿号，表示多个不同尺寸，而不是一个小数。[三丰目录第113页](https://www.mitutoyo.com.cn/Mitutoyo2024/pageindices/index113.html)
- 同一批产品的多个尺寸、套装构成可以被并列书写。因此不能看到“5、8”就自动拼成“5.8”，也不能自动拆成两行、各复制一次数量。
- 对“钻头，中5、8，100支”这种单行，结合本店照片，可提出“Φ5.8”的候选；但这个候选是OCR推断，不是证明供应商用顿号表达小数。需要原图、小数笔迹、商品目录或本店已确认记录进一步核对。
- 厂商跨语言资料还可能使用逗号小数，例如霍夫曼中文数据表出现“6,35”。逗号、顿号和点不能统一强制替换。[霍夫曼铰刀数据表](https://cdn.hoffmann-group.com/dsh/zh-CN/dsh_zh-cn_1186310.pdf)

## 2. 规格能否出现“中”字

可以。不能把所有“中”都替换成直径符号。

- 世达实际产品有“中齿平锉6英寸”，“中齿”是有效商品描述；其目录还有“中孔花形旋具头”。应整体保留。[世达中齿平锉](https://cloud.satatools.com/goods/show_03915.aspx)、[世达产品目录](https://oss.satatools.com/sataportal2022/202309/28/202309281637520544.pdf)
- 三丰目录真实使用 φ、ø 表达直径，例如 φ30、ø45。票据手写或OCR中的“中8”“巾16”可能来自相似符号，但必须按字段和商品类别判断。[三丰目录](https://www.mitutoyo.com.cn/Mitutoyo2024/pageindices/index113.html)
- “中齿”“中孔”等词不能替换；单独前缀“中”加数字、出现在钻头或铰刀的直径规格位置时，可以生成直径候选，保留原文待确认。
- 本次资料没有证明“中”是通用、正式的直径标记，也没有证明每个供应商都这样手写。

## 3. 分类理解，不做全局字符替换

| 类别 | 可核对的形式或示例 | 整理时的重点 |
| --- | --- | --- |
| 麻花钻 | 厂家用直径、总长、沟槽长等不同参数；Dormer A10010.0 的直径10mm、总长133mm、沟槽长87mm | 商品编号、直径、总长不能混为一个数字；毫米未写在票据上时只作候选解释 |
| 丝锥、螺纹件 | M6、M8及对应螺距；有粗牙、细牙区别 | M是螺纹系列的一部分，不改成Φ。M6不等于直径6mm钻头；未明确螺距时不擅自补齐细牙规格 |
| 螺纹规格表达 | M8×0.75；目录也可能用不同字段分别写公称尺寸、螺距和长度 | ×后面是螺距还是长度由商品和字段决定，不能全都解释成长度 |
| 铰刀 | 直径及H7等公差相关描述 | H7不能丢弃；供应商具体规格、刀具公差和所加工孔公差要区分，不将所有尾缀都当尺寸 |
| 量具 | 量程0～150、0～200，分度值0.01mm或0.02mm | 量程、分辨力/分度值、精度是不同字段；0～150是范围，不是乘法，也不拆为两件商品 |
| 锉刀 | 中齿平锉6英寸 | 名称、锉齿描述、标称规格与产品尺寸字段分开。世达该例标称6英寸，L字段为262mm，不能简单换算后覆盖L字段 |
| 螺丝批、批头 | PH1、PH2、PH3，SL3，T8、T10等 | 字母属于类型或规格；PH2中的2不能当数量。目录中“中孔”属于有效描述 |
| 气动、管接头 | R1/4、Rc1/4、NPT1/4等 | 分数字符和螺纹类型必须保留；不能把1/4直接当成外径6.35mm，也不能把不同螺纹体系合并 |
| 砂纸 | P120等粒度标记，另有宽度与长度 | P是有效规格字符，不是都由Φ误识别而来。P120不能全局改为Φ120 |
| 磨棒等多参数件 | 本店原单“3×1-3”“3×6-8” | 尚未获得该厂商对应目录；整体保留，不擅定为直径×长度，不把连接号自动解释为尺寸范围 |

本表示例是分类识别依据，不是全部商品的统一编码公式。

## 4. 名称整理的字段边界

建议保存：名称原文、规格原文、建议名称、建议规格、匹配商品、依据、待核对项。规格中只为匹配统一全角/半角或明显多余空格时，也保留原始字符串。

- 厂商/品牌：用于匹配来源，不自动塞进商品基本名称。
- 基本名称：如钻头、丝锥、铰刀、磨棒、锉刀，必须结合商品和原文确定。
- 修饰信息：材质、涂层、形状、齿型、粗细牙等，不能为了缩短名称删除。
- 规格：保留字母、尺寸、范围、公差和顺序；不把所有数字都当毫米直径。
- 交易单位：支、个、把、套等，和mm、inch这样的规格尺寸单位分开。纸面“支”的OCR变成纯数字时，应保留疑点而非移入数量。
- 别名：只有用户确认或本店档案有依据才作为长期匹配规则，不能仅按发音或形似字推断品牌、型号。

## 5. 给小五的候选规则（尚未接入自动改写）

1. 先判断商品类别，再解释符号；原图和本厂商已确认档案优先于通用目录。
2. Φ、φ、ø等在直径上下文可归入同类检索，但源规格保留原貌；P、中、巾只生成可能的直径候选，不能全局替换。
3. “5、8”至少保留“两个规格”与“5.8误识别”的可能；看商品、行结构、照片和厂商记录，不自动改数值、不复制数量。
4. 连续省略名称时只沿用最近明确商品名，不沿用上一行数量、单价、金额或单位；新商品、空行、表格边界中断沿用。
5. ×、x、*可能表示尺寸连接，但也可能处于型号、计算式中；连接号可能是范围、型号或参数分隔，按类别判断。
6. M、PH、SL、T、P、H7、R、Rc、NPT及分数不能作为“脏字符”清理。具体含义必须由商品类别和目录支撑。
7. 找到唯一目录候选也不等于照片读对了。高风险数值差异保留为待确认，不借行业知识伪造原文。
