# 采购识别模型耗时优化与对照测试（2026-10-24）

本轮目标：减少采购识别的模型输入与重复输出。使用现有配置的 deepseek-flash 和真实腾讯OCR。只执行百科查询与草稿预览，不写业务数据库，未部署。

## 修改内容

- 明确要求创建采购单、单附件、单表格、表头可解析时，使用采购专用规则；用途不明、查询、文件生成、多附件、多表格、截断内容等沿用完整规则。保留对话历史和原有工具权限。
- 模型以OCR第N行的行号关联来源，不再生成rawName、rawSpecification的重复文字；程序补回原始字段，将整张OCR记录写入来源说明。来源行无效或重复时拒绝生成该草稿。
- 模型以有限的reviewCodes表达疑点，程序生成中文提示、续行核对提示和金额差异提示。编辑页收到的仍是原有单据格式，不展示这些内部标记。
- 请求记录输入大小、输出大小及服务商返回的用量。流式调用另记首个有效事件耗时；本次真实对照采用非流式请求，因此没有真实首字时间。
- 因本轮识别质量出现回退，精简方式默认关闭，正常请求继续使用原规则；只有显式设置agent.model.procurement-recognition-compact=true才启用。真实测试显式开启该开关，旧方式对照显式关闭。
