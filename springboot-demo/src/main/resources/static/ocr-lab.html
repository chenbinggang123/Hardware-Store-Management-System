配置与帮助

以下是后端配置说明。密钥填写在服务器本地配置文件中，修改后需重启后端。

模型服务

在 springboot-demo/agent.local.env 中配置：

AGENT_MODEL_ENABLED
设为 true；密钥为空时，本地启动脚本会暂时关闭模型。
AGENT_MODEL_BASE_URL
模型服务的 Chat Completions 兼容接口根地址。
AGENT_MODEL_NAME
填写服务商提供的模型名称。
AGENT_MODEL_API_KEY
仅在后端填写模型密钥。
AGENT_MODEL_TIMEOUT_SECONDS
请求超时秒数。
腾讯云 OCR 与单据识别
TENCENT_OCR_SECRET_ID / SECRET_KEY
腾讯云 OCR 凭证，仅保存在后端配置。
TENCENT_OCR_REGION
服务地域，例如 ap-guangzhou。
OCR_PROVIDER / TABLE_OCR_MODE
腾讯云直连均可设为 tencent，分别控制对话附件与文件任务识别。
TENCENT_OCR_TIMEOUT_SECONDS / TABLE_OCR_TIMEOUT_SECONDS
识别请求超时秒数。
TABLE_OCR_URL
腾讯云直连时留空；仅使用自建 HTTP 适配服务时填写。

识别只创建待核对文件任务，不会自动登记采购或修改库存。

数据库与本地启动

电脑端页面由后端直接提供。在项目目录运行 .\run-dev.ps1 启动；更改配置后重启后端。

默认本地数据库为 MySQL 的 hardware_store。通过 DB_HOST、DB_PORT、DB_NAME、DB_USERNAME 和 DB_PASSWORD 覆盖连接参数。

文件任务与对话历史会保存到当前连接的后端。

对话、文件与操作确认

快捷问题只填入输入框，你可以补充条件后发送。回复中的文件可直接下载。

识别完成后点击“加入当前对话”，下一条消息才会携带该识别文本。发送前可以查看或移除；已发送的内容会保留在该对话历史中。

涉及写入业务数据时，请先核对确认卡。执行完成后会显示结果，已处理的按钮不会重复提交。
