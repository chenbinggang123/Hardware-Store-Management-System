# 紧固件与钉丝网

单位为零售常见候选；散装、按重量或成套销售时以本店实际方式为准。

| 建议名称 | 常见别名/口语写法 | 常见单位候选 | 识别注意 |
| --- | --- | --- | --- |
| 六角螺栓 | 外六角螺栓、六角栓 | 个、支、盒、套 | “螺栓”与机螺钉不能只凭俗称互换 |
| 内六角螺栓 | 杯头螺丝、内六角圆柱头螺钉 | 个、支、盒 | 杯头通常指圆柱头样式，规格需核对 |
| 沉头螺钉 | 平头螺丝、沉头机螺钉 | 个、支、盒 | 沉头形状不等于自攻类型 |
| 圆头螺钉 | 盘头螺钉、圆头机丝 | 个、支、盒 | 与圆头自攻螺钉区分 |
| 自攻螺钉 | 自攻丝、自攻螺丝 | 个、支、盒、包 | 泛称，需确认头型、尾型及用途 |
| 钻尾螺钉 | 自钻螺钉、燕尾丝、钻尾丝 | 个、支、盒、包 | “燕尾丝”常作口语，不等于所有自攻丝 |
| 木螺钉 | 木螺丝 | 个、支、盒 | 与机螺钉、自攻螺钉结构不同 |
| 干壁钉 | 石膏板钉、墙板钉 | 个、盒、箱 | 黑色只是常见表面，不作唯一判断 |
| 紧定螺钉 | 止付螺丝、机米螺丝 | 个、支、盒 | 端部有平端、尖端、凹端等差异 |
| 双头螺柱 | 双头螺栓、牙棒螺柱 | 支、个、盒 | 与全牙丝杆不是同一商品 |
| 全牙丝杆 | 牙条、通丝、全螺纹杆 | 支、根、米 | 长度/材质关键；“丝杆”也可能指传动件 |
| 螺母 | 螺帽 | 个、只、盒、包、千克 | “螺帽”通常指螺母，但需看上下文 |
| 六角螺母 | 六角帽 | 个、只、盒、包、千克 | 核对螺纹规格和材质 |
| 防松螺母 | 尼龙锁紧螺母、锁紧帽 | 个、只、盒 | 有多种结构，不能仅凭“防松帽”合并 |
| 蝶形螺母 | 蝴蝶螺母、元宝螺母 | 个、只、盒 | 地方叫法可能指不同外形 |
| 法兰螺母 | 带垫螺母 | 个、只、盒 | 法兰面/齿形需核对 |
| 平垫圈 | 平垫、平垫片 | 个、片、盒、包、千克 | 尺寸、厚度、材质不同不可合并 |
| 弹簧垫圈 | 弹垫、弹簧垫片 | 个、片、盒、包 | 口语“弹垫”常指此件，规格需核对 |
| 开口挡圈 | 卡簧、弹性挡圈 | 个、只、盒 | 轴用/孔用及尺寸不同 |
| 膨胀螺栓 | 膨胀螺丝、膨胀栓 | 个、套、盒 | 常见成套，确认是否含螺母/垫片 |
| 膨胀管 | 塑料膨胀管、胶塞、墙塞 | 个、包、盒 | 与金属膨胀螺栓不是一类 |
| 膨胀钩 | 膨胀挂钩、膨胀钩子 | 个、套 | 与普通膨胀螺栓用途不同 |
| 抽芯铆钉 | 拉铆钉、拉钉 | 个、盒、包 | 直径、长度、材质需核对 |
| 拉铆螺母 | 拉帽、铆螺母 | 个、盒、包 | 与抽芯铆钉不同 |
| 铁钉 | 圆钉、元钉 | 千克、盒、包、个 | 散装常按重量；不可假设每公斤支数 |
| 水泥钉 | 钢钉、混凝土钉 | 千克、盒、包、个 | 票面“钢钉”需结合规格判断 |
| 码钉 | U形钉、气排钉（需核实） | 盒、盒/条、箱 | 码钉与气排钉设备和规格不同，不自动合并 |
| 钢排钉 | 排钉、直钉（气动） | 盒、条、箱 | 排列角度/枪型决定是否适配 |
| 钢丝 | 铁丝、镀锌铁丝 | 千克、卷、米 | 材质、线径和卷重决定规格 |
| 扎丝 | 绑丝、捆扎丝 | 千克、卷、把 | 工地绑扎丝与扎带不是一种物品 |
| 铁丝网 | 钢丝网、金属网 | 平方米、卷、米 | 网孔、丝径、宽度都要核对 |
| 纱窗网 | 窗纱、金刚网（需核实材质） | 平方米、卷、米 | “金刚网”不是普通纱窗网的无条件别名 |
| 钢丝绳 | 钢缆 | 米、卷、千克 | 直径、结构、承载等级不可省略 |
| 钢丝绳卡头 | 绳卡、卡头 | 个、只、套 | 需与钢丝绳直径匹配 |
| 喉箍 | 管箍、卡箍、抱箍（泛称） | 个、只、包 | “抱箍”可能是其他结构，按照片/规格核实 |
| U形卡 | U型螺栓、管卡（部分场景） | 个、套 | 地方叫法范围不一，需核形状 |
| 圆柱销 | 定位销 | 个、支、盒 | 材质、直径和长度不同 |
| 开口销 | 发夹销（非严格同义） | 个、支、盒 | 发夹销与开口销形状不同，不自动合并 |
| 平键 | 键条、键 | 支、根、米 | 常需切割，按根或长度销售 |
| 吊环螺栓 | 羊眼螺栓（部分口语） | 个、只 | 与膨胀吊环、螺钉式羊眼区分 |

名称分类交叉参考：[中国国际五金展展品范围](https://www.cihs.com.cn/single-data.jsp?mid=15)、[紧固件商品分类目录](https://brt.361ding.com/item/itemsSearch.htm?groupID=9162004&orderByClause=default&pageNo=1&pageSize=15)。别名和单位为候选整理，非标准换算依据。
