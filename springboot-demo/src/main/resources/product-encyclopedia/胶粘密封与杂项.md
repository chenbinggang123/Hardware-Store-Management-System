# 胶粘密封与杂项

| 建议名称 | 常见别名/口语写法 | 常见单位候选 | 识别注意 |
| --- | --- | --- | --- |
| 502胶 | 瞬干胶、快干胶（泛称） | 瓶、支、盒 | 不同胶水不能仅按“快干胶”合并 |
| 玻璃胶 | 硅酮密封胶、硅胶（口语易混） | 支、箱 | 酸性/中性、颜色、容量不同 |
| 结构胶 | 建筑结构胶（泛称） | 支、组 | 结构用途与普通密封胶区别明显 |
| 云石胶 | 大理石胶、石材胶（泛称） | 组、桶 | 配套固化剂、颜色和容量不同 |
| AB胶 | 双组份胶、环氧胶（泛称） | 组、套、支 | 成分和用途不同，不能按“AB胶”一概合并 |
| PVC胶水 | PVC管胶、管道胶（需核材质） | 瓶、桶 | 适用管材、容量和固化要求不同 |
| 白乳胶 | 木工胶（常见用途） | 瓶、桶 | 白乳胶不是所有木工胶的同义词 |
| 免钉胶 | 液体钉、免钉胶水 | 支、瓶 | 品牌、容量、适用材料不同 |
| 双面胶 | 双面胶带 | 卷、卷/个 | 泡棉、无痕、薄款不能只按总称合并 |
| 泡棉胶带 | 海绵双面胶、海绵胶 | 卷 | 厚度、宽度、胶系不同 |
| 美纹纸胶带 | 美纹纸、遮蔽胶带 | 卷 | 宽度、耐温和粘性不同 |
| 生料带 | 水暖密封带、PTFE密封带 | 卷 | 与水暖条目为同一主词；品牌规格需分 |
| 密封条 | 防撞条、门窗密封条（具体款） | 米、卷、根 | 截面、材质、尺寸和用途不同 |
| 玻璃胶枪 | 打胶枪、胶枪 | 把、支 | 手动/电动及适用胶筒不同 |
| 油漆刷 | 刷子、羊毛刷（细分类） | 把、支 | 毛材质、宽度不同 |
| 滚筒刷 | 滚筒、滚刷 | 把、支、套 | 毛长、宽度及是否含手柄不同 |
| 刮板 | 刮刀、批刮板（泛称） | 把、个 | 用途形状不同，避免过度合并 |
| 口罩 | 防尘口罩（细分类） | 个、只、包 | 普通防尘与防护等级口罩不可混 |
| 手套 | 劳保手套（泛称） | 双、副、包 | 常按双销售；材质和防护类型差异大 |
| 护目镜 | 防护眼镜 | 副、个 | 防冲击/防尘等用途须区分 |
| 安全帽 | 工地帽（口语） | 顶、个 | 颜色不等于防护等级 |
| 雨鞋 | 胶鞋（部分口语） | 双、副 | 筒高、尺码、材质不同 |
| 扫帚 | 扫把、笤帚（地区口语） | 把 | 软硬、材质和用途不同 |
| 拖把 | 墩布（地区口语） | 把、套 | 拖把头与杆/整套需区分 |
| 垃圾袋 | 塑料袋（泛称） | 卷、包、只 | 尺寸、厚度和包装数量需核 |
| 电池 | 干电池（泛称） | 节、对、板、盒 | 型号、化学体系及包装不同 |
| 手电筒 | 电筒 | 个、把 | 与照明电料条目为同一主词 |
| 钥匙胚 | 配钥匙胚、钥匙坯 | 把、支、个 | 型号齿形决定能否匹配 |

胶粘与杂项类别为五金零售的常见扩展项。包装单位尤其受品牌和进货包装影响，正式建档时以实物标签和门店销售方式为准。
