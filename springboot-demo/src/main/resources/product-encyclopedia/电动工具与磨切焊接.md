# 电动工具与磨切焊接

工具本体常按台/把/套销售，耗材常按片/支/盒/包/千克销售；具体包装必须核实。

| 建议名称 | 常见别名/口语写法 | 常见单位候选 | 识别注意 |
| --- | --- | --- | --- |
| 手电钻 | 电钻、手枪钻 | 台、把、套 | 有线/充电款、电压和夹头不同 |
| 冲击钻 | 冲击电钻 | 台、把、套 | 不等同电锤/电镐 |
| 电锤 | 电锤钻、锤钻 | 台、把、套 | SDS接口及功率不同 |
| 电镐 | 电锤镐（口语） | 台、把、套 | 与电锤功能不同 |
| 角磨机 | 角向磨光机、磨光机（泛称） | 台、把、套 | 片径、功率和轴心规格不同 |
| 电圆锯 | 圆锯、电锯（泛称） | 台、把 | 锯片直径、用途不同 |
| 云石机 | 石材切割机、切割机（泛称） | 台、把 | 与角磨机不自动合并 |
| 曲线锯 | 线锯、往复锯（易混） | 台、把、套 | 曲线锯与往复锯不同 |
| 电动螺丝批 | 电批、电动起子 | 台、把、套 | 与冲击起子和电钻区分 |
| 电动扳手 | 风炮（气动常用名，易混） | 台、把、套 | 电动与气动不能用别名合并 |
| 热风枪 | 吹风枪（口语易混） | 台、把 | 与吹风机/焊枪不同 |
| 空气压缩机 | 空压机、气泵（泛称） | 台、套 | 容积、功率、压力需核对 |
| 麻花钻头 | 麻花钻、钻头（泛称） | 支、根、盒、套 | 材质、直径、柄型不同 |
| 冲击钻头 | 电锤钻头（易混） | 支、根 | 圆柄/方柄/SDS及用途不同 |
| 木工钻头 | 木钻、木工麻花钻 | 支、根、套 | 尖头形状及直径需核 |
| 开孔器 | 开孔钻、取孔器（泛称） | 个、支、套 | 材料适用范围和孔径不同 |
| 丝锥 | 攻丝锥、丝攻 | 支、付、套 | 机用/手用、牙距需核对 |
| 板牙 | 套丝板牙、圆板牙 | 个、付、套 | 螺纹规格与丝锥对应但不能替代 |
| 切割片 | 砂轮切割片、切片 | 片、盒、箱 | 金属/石材及外径厚度不同 |
| 角磨片 | 磨片、砂轮片（泛称） | 片、盒 | 切割片与打磨片用途不同 |
| 百叶片 | 百叶轮、千叶片 | 片、盒 | 粒度、直径、孔径不同 |
| 砂轮片 | 磨轮（泛称） | 片、个 | 平形/碗形等不可仅按“磨片”认定 |
| 砂纸 | 水砂纸、干磨砂纸（按用途） | 张、包、卷 | 纸基、粒度、尺寸不同 |
| 砂布 | 砂布卷、布砂纸 | 张、米、卷 | 与砂纸材质及包装区分 |
| 钢丝轮 | 钢丝刷轮、碗型钢丝轮 | 个、片 | 形状、丝径、接口不同 |
| 磨头 | 砂轮磨头、羊毛磨头（易混） | 个、支、盒 | 磨料类型差异大，必须看名称/图 |
| 电焊条 | 焊条 | 千克、包、箱 | 牌号和直径关键，重量包装不固定 |
| 焊丝 | 气保焊丝、二氧化碳焊丝（特定） | 千克、卷、盘 | 实芯/药芯及材质不同 |
| 焊锡丝 | 锡丝、焊锡 | 卷、支、千克 | 含锡比例及线径不同 |
| 焊锡膏 | 助焊膏（易混） | 盒、罐、支 | 焊锡膏与助焊剂需核实成分用途 |
| 电焊钳 | 焊钳、焊把钳 | 把、个 | 电流等级和接口不同 |
| 焊帽 | 电焊面罩 | 个、把 | 自动变光/手持式不同 |

分类参考：[中国五金制品协会工具五金类别](https://www.chinahardware.org.cn/single-data.jsp?mid=14)、[中国国际五金展展品范围](https://www.cihs.com.cn/single-data.jsp?mid=15)。
