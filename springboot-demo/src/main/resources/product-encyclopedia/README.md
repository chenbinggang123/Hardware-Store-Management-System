# 商品百科

规格与识别疑点的分类资料另存于 `product-knowledge/specification-rules.json`，按名称和类别检索少量相关条目，不将全部百科加入模型上下文。查询工具现支持 `category`、`originalSpecification`、`issue`，可返回规格建议、解释和来源；识别草稿也会自动附上相关资料。详见项目 `docs/百科核对接入说明.md`。

本目录用简单 Markdown 记录本店已确认的商品资料，供整理收据、采购单、报价表和商品清单时查询名称、规格、单位及常见写法。

## 使用规则

- 只把用户确认或商品档案核实过的信息作为正式资料；OCR 的猜测不能直接入百科。
- 识别到单据商品时，先按商品名称、规格、条码和别名查找本目录。匹配唯一时可用标准名称和单位辅助核对。
- 同名不同规格、相似名称或单位冲突时，列出候选并请用户确认，不自动合并。
- 单据上的原始写法可以记录为别名，但必须确认它对应哪个商品。保留原始写法，不覆盖标准名称。
- 若单据单位与商品档案单位不同，只有确认过换算关系后才换算数量；进货单位、销售单位和库存基础单位要区分。
- 数量、单价和金额的 OCR 错误不能仅凭商品百科自动修正。百科可提示商品及单位候选；数字仍需对照票面和验算。
- 新商品条目按 `_商品条目模板.md` 创建，文件名建议使用标准商品名称；在下方索引增加链接。
- 用户纠正后，只在明确确认该写法可复用于今后同类商品时，才加入别名。仅本单修正不自动变成长期规则。

后端 agent 工具 `search_product_encyclopedia` 接收 `keyword`（可选 `limit`），返回候选名称、别名、常见单位候选、分类和易混提示。它只查本词库，不查本店商品主档；查询业务商品、条码、价格或库存仍须使用相应业务工具。

## 资料依据

- [中国五金制品协会：协会简介及五金产品类别](https://www.chinahardware.org.cn/single-data.jsp?mid=14)：工具五金、建筑五金、锁具、卫浴及给排水配件等分类依据。
- [中国国际五金展：展品范围](https://www.cihs.com.cn/single-data.jsp?mid=15)：手工具、电动工具、磨料、紧固件、门窗家具五金、管件阀门等类别依据。
- [佰瑞特紧固件商品分类目录](https://brt.361ding.com/item/itemsSearch.htm?groupID=9162004&orderByClause=default&pageNo=1&pageSize=15)：紧固件商品名称、细分类及市场叫法的交叉参考；商业目录不作为单位标准。
- [上海市建设工程材料及设备类价格信息（示例，PDF）](https://swj.sh.gov.cn/cmsres/a4/a45e0eec54754936bccf7fbff5dee41f/ce6b9c8cbdc42ccf997a37f12adb5c1e.pdf)：部分建材五金按个、套、片、张、千克、平方米等计量的例证。此类工程计价单位不等同于本店零售单位。

本词库是人工归纳的检索起点，不是标准术语全集。新增别名和单位时应记录来源及确认状态；存在歧义的写法仅作为“待核别名”，不得直接建立自动纠错映射。
