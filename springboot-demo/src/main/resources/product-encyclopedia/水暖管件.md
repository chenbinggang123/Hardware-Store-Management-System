# 水暖管件

同一管件可能按个、根、米、卷、套或重量销售。材质、口径、压力等级和连接方式是区分商品的关键，百科不推定换算关系。

| 建议名称 | 常见别名/口语写法 | 常见单位候选 | 识别注意 |
| --- | --- | --- | --- |
| PPR给水管 | PPR管、热熔管 | 根、米 | 冷热水、压力等级、口径不同 |
| PVC排水管 | PVC管、排水管（泛称） | 根、米 | 排水管与电工套管不同 |
| PVC电工套管 | 线管、穿线管（泛称） | 根、米 | 与给排水PVC管区分 |
| PE给水管 | PE管、黑管（口语） | 米、卷、根 | “黑管”可能指其他材质，慎用 |
| 铝塑管 | 铝塑复合管 | 米、卷 | 口径、层数及接头体系不同 |
| PPR弯头 | 弯头、90度弯头（特定角度） | 个 | 角度、口径、冷热水型号不同 |
| PPR三通 | 三通、等径三通（特定） | 个 | 等径/异径需区分 |
| PPR直接 | 直通、套接（口语） | 个 | 口径需匹配 |
| PPR异径接头 | 变径、大小头（泛称） | 个 | 方向、口径组合不同 |
| PPR内丝弯头 | 内牙弯头、内螺纹弯头 | 个 | 螺纹规格需核对 |
| PPR外丝直接 | 外牙直接、外螺纹接头 | 个 | 材质嵌件与牙型不同 |
| PVC弯头 | 排水弯头、PVC弯 | 个 | 排水/电工管配件区分 |
| PVC三通 | 排水三通 | 个 | 顺水三通、斜三通等不可合并 |
| PVC直接 | PVC直通、套筒 | 个 | 管径需核实 |
| PVC管卡 | 管夹、管扣（泛称） | 个、包 | 管径与固定形式不同 |
| 球阀 | 水阀、球形阀（口语） | 个、只 | 口径、材质、内外丝及压力不同 |
| 闸阀 | 闸门阀 | 个、只 | 不等同球阀 |
| 止回阀 | 单向阀、逆止阀 | 个、只 | 安装方向、类型和口径不同 |
| 角阀 | 三角阀、八字阀（部分地区） | 个、只 | 螺纹和冷热标识要核 |
| 水龙头 | 龙头、笼头（地区口语） | 个、只、套 | 面盆/厨房/洗衣机等用途区分 |
| 花洒 | 淋浴喷头、莲蓬头（口语） | 个、套 | 手持花洒与顶喷不同 |
| 淋浴软管 | 花洒管、喷头软管 | 根、条、套 | 长度、接头规格不同 |
| 编织软管 | 上水软管、进水管（泛称） | 根、条 | 长度、内径及螺纹不同 |
| 水表 | 水量表 | 个、只 | 口径、冷热、精度等级不同 |
| 水表接头 | 水表活接、表接 | 个、套 | 需区分一对/单个、口径及材质 |
| 生料带 | 聚四氟乙烯密封带、PTFE带 | 卷 | 厚度、宽度、长度不同 |
| 麻丝 | 油麻、密封麻 | 把、包、千克 | 常与铅油配合，但不能默认成套 |
| 水管钳 | 管钳、管子钳 | 把 | 与手工具条目同一主词 |
| 管箍 | 管卡、卡箍（泛称） | 个、只 | 结构多样，需看材质/形状 |
| 地漏 | 下水地漏、地漏芯（不同部件） | 个、只、套 | 地漏总成与地漏芯须区分 |
| 下水器 | 面盆下水、落水器 | 个、套 | 弹跳/翻板/提拉款不同 |
| 下水软管 | 排水软管、洗脸盆下水管 | 根、条 | 长度、接口、伸缩结构不同 |
| 水箱配件 | 马桶水箱配件（集合称谓） | 个、套 | 进水阀、排水阀等不是同一商品 |
| 马桶进水阀 | 水箱进水器 | 个、套 | 高度、接口和适配水箱不同 |
| 马桶排水阀 | 水箱排水器、冲水阀（易混） | 个、套 | 排水阀与冲洗阀定义有差异 |

分类参考：[中国五金制品协会卫浴及给排水产品类别](https://www.chinahardware.org.cn/single-data.jsp?mid=14)。
