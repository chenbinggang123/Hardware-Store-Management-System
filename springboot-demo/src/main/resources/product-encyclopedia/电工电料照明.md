# 电工电料照明

电线电缆可按米、卷、盘或千克计；开关插座及配件按个/只/盒较常见。不同线径、芯数、额定电压和包装不可合并。

| 建议名称 | 常见别名/口语写法 | 常见单位候选 | 识别注意 |
| --- | --- | --- | --- |
| 铜芯电线 | 电线、单芯线（需核规格） | 米、卷 | 线径、平方数、颜色及品牌不同 |
| 护套线 | 双芯护套线、三芯护套线 | 米、卷 | 芯数和平方数关键 |
| 电缆 | 电力电缆、电线（泛称易混） | 米、卷、盘 | 芯数、截面积、铠装和电压等级不同 |
| 网线 | 网络线、双绞线 | 米、箱、卷 | 类别、屏蔽、芯材不同 |
| 电话线 | 电话软线 | 米、卷 | 芯数和用途不同 |
| 电缆扎带 | 尼龙扎带、扎带 | 包、袋、条 | 长宽、颜色、材质需核 |
| 电工胶带 | 绝缘胶布、黑胶布（易混） | 卷、个 | PVC绝缘带和布基胶带不可混 |
| 热缩管 | 热缩套管 | 米、根、包 | 收缩倍率、直径和颜色不同 |
| 接线端子 | 端子、接线帽（泛称） | 个、只、包、盒 | 压线端子、端子排、接线帽各异 |
| 端子排 | 接线排、排线端子 | 条、个 | 位数、间距、电流等级不同 |
| 铜鼻子 | 铜线鼻、线耳、铜端子（口语） | 个、只、包 | 开口/闭口、孔径及线径需核 |
| 线卡 | 钢钉线卡、圆线卡（细分） | 包、盒、个 | 线径、钉长、形状不同 |
| 接线盒 | 暗盒、开关盒（具体款） | 个、只、盒 | 底盒/明盒、尺寸深度不同 |
| 穿线管 | 电工套管、线管 | 根、米 | PVC/金属、管径及壁厚不同 |
| 线槽 | PVC线槽、走线槽 | 根、米 | 尺寸、颜色、槽盖是否一体 |
| 开关 | 墙壁开关、面板开关 | 个、只、套 | 单控/双控/多开及面板系列不同 |
| 插座 | 电源插座、墙插 | 个、只、套 | 五孔/三孔/带USB等款式不同 |
| 插头 | 电源插头、插头头子 | 个、只 | 两脚/三脚、额定电流不同 |
| 插线板 | 排插、接线板、拖线板 | 个、只 | 长度、孔位、线径和安全规格不同 |
| 漏电保护器 | 漏保、漏电开关（口语） | 个、只 | 额定电流、极数、漏电动作值不同 |
| 断路器 | 空开、空气开关 | 个、只 | 额定电流、极数、分断能力不同 |
| 配电箱 | 电箱、开关箱（部分场景） | 个、只、套 | 箱体与已装元件的箱体总成区分 |
| 灯泡 | LED灯泡、球泡灯 | 个、只、盒 | 功率、色温、灯头规格不同 |
| 灯管 | LED灯管、日光灯管（旧称） | 根、支、盒 | 长度、接口和驱动方式不同 |
| 灯座 | 灯头、灯口（口语） | 个、只 | 螺口规格、材质、电压不同 |
| 手电筒 | 电筒、应急灯（易混） | 个、把 | 电池/充电及功能不同 |
| 测电笔 | 电笔、验电笔 | 支、个 | 与手工具同一主词；接触/感应类型不同 |
| 万用表 | 电表（泛称） | 台、个 | 指针/数字、量程、功能不同 |
| 电工刀 | 剥线刀（易混） | 把、支 | 绝缘等级和刀型不同 |

电线及配电类名称依行业常见叫法整理；单位没有统一零售默认值，应按线缆商品的实际计价方式记录。
