# 门窗家具锁具

| 建议名称 | 常见别名/口语写法 | 常见单位候选 | 识别注意 |
| --- | --- | --- | --- |
| 合页 | 铰链、门合页（常见叫法） | 个、片、付 | 普通合页与柜门铰链结构不同 |
| 子母合页 | 子母铰链 | 片、付 | 左右/尺寸需核 |
| 柜门铰链 | 橱柜铰链、烟斗合页（部分款） | 个、只 | 直弯、中弯、大弯和阻尼款不同 |
| 抽屉滑轨 | 滑轨、导轨 | 副、付、套 | 长度、承重、缓冲结构不同 |
| 钢珠滑轨 | 三节轨、滚珠滑轨 | 副、付 | 与隐藏轨、托底轨不同 |
| 门锁 | 房门锁、室内门锁（泛称） | 把、套 | 锁体、面板、方向和中心距不同 |
| 球形锁 | 球锁、球头门锁 | 把、套 | 卫浴/通道/隐私功能不同 |
| 挂锁 | 铜挂锁、铁挂锁（材质分类） | 把、个 | 锁梁尺寸和材质不同 |
| 锁芯 | 锁胆、锁心 | 个、只 | 长度、偏心距、级别和钥匙数不同 |
| 插芯锁体 | 锁体、门锁锁体 | 个、只 | 尺寸和锁舌方向关键 |
| 门吸 | 门碰、地吸（按安装方式） | 个、套 | 墙吸/地吸及材质不同 |
| 门碰 | 门挡、门吸（口语易混） | 个、只 | 门碰可能泛指不同结构，按外观核实 |
| 闭门器 | 自动闭门器、关门器 | 个、套 | 承重范围、安装方式不同 |
| 地弹簧 | 地弹簧门轴 | 个、套 | 规格、承重和开门角度不同 |
| 插销 | 门插销、插销锁（泛称） | 个、套 | 明装/暗装、长度不同 |
| 拉手 | 把手、柜门拉手 | 个、只、套 | 孔距、长度、材质不同 |
| 家具角码 | 角码、直角码 | 个、只、包 | 形状、孔位、厚度不同 |
| 层板托 | 隔板托、玻璃托（细分） | 个、只、包 | 木层板/玻璃层板款不同 |
| 家具脚 | 柜脚、调节脚 | 个、只、套 | 高度、承载、调节结构不同 |
| 万向轮 | 活动轮、脚轮 | 个、只、套 | 带刹/不带刹、轮径和材质不同 |
| 定向轮 | 固定轮、脚轮 | 个、只、套 | 与万向轮不同 |
| 玻璃夹 | 玻璃固定夹 | 个、只、套 | 玻璃厚度、安装位置和材质不同 |
| 窗撑 | 风撑、滑撑（具体结构） | 根、支、套 | 平开窗/上悬窗型号不同 |
| 窗轮 | 滑轮、门窗滚轮 | 个、只、套 | 推拉窗/推拉门及轮槽尺寸不同 |
| 密码锁 | 数字锁（泛称） | 把、套 | 机械/电子、用途与安装尺寸不同 |
| 防盗链 | 门链、扣链 | 条、套 | 长度和材质不同 |

类别参考：[中国五金制品协会锁具及建筑五金分类](https://www.chinahardware.org.cn/single-data.jsp?mid=14)、[中国国际五金展展品范围](https://www.cihs.com.cn/single-data.jsp?mid=15)。
