# 手动工具

| 建议名称 | 常见别名/口语写法 | 常见单位候选 | 识别注意 |
| --- | --- | --- | --- |
| 活动扳手 | 活扳手、活口扳手、活络扳手 | 把、支 | 不同地区叫法不同；核对开口尺寸 |
| 开口扳手 | 呆扳手、开口扳子 | 把、支、套 | 单头/双头及规格不同 |
| 梅花扳手 | 梅花扳子、闭口扳手（泛称） | 把、支、套 | 两端尺寸可能不同 |
| 两用扳手 | 两用扳子、开口梅花扳手 | 把、支、套 | “两用”通常指开口+梅花 |
| 套筒扳手 | 套筒、套筒组套 | 个、支、套 | 单个套筒与整套不能合并 |
| 棘轮扳手 | 快速扳手、棘轮柄 | 把、支、套 | 接口方头尺寸需核对 |
| 内六角扳手 | 内六角匙、六角匙 | 把、支、套 | 公制/英制、球头款不同 |
| 管钳 | 管子钳、管子扳手 | 把、支 | 与水泵钳用途相近但结构不同 |
| 水泵钳 | 水泵钳子、鲤鱼钳（口语易混） | 把、支 | 与鲤鱼钳不保证完全同型 |
| 尖嘴钳 | 尖头钳 | 把、支 | 长短、绝缘及用途不同 |
| 钢丝钳 | 老虎钳、钳子（泛称） | 把、支 | “钳子”范围过宽，不用于自动匹配 |
| 斜口钳 | 斜嘴钳、剪钳（泛称） | 把、支 | 与电缆剪、断线钳区分 |
| 断线钳 | 断线剪、大力钳（易混） | 把、支 | 大力钳也常指锁紧钳，需核形状 |
| 剥线钳 | 剥线器 | 把、支 | 自动/手动及线径范围不同 |
| 压线钳 | 冷压钳、端子钳（泛称） | 把、支、套 | 需区分端子规格和压接类型 |
| 螺丝刀 | 起子、改锥、旋具（地区用语） | 把、支、套 | 十字/一字/梅花等头型必须保留 |
| 十字螺丝刀 | 十字起子 | 把、支 | 规格PH/长度不同 |
| 一字螺丝刀 | 平口起子、一字起子 | 把、支 | 刀口宽度和长度不同 |
| 电笔 | 测电笔、验电笔 | 支、个 | 感应式/接触式不同，安全等级需核 |
| 羊角锤 | 起钉锤、羊角锤子 | 把、把/支 | 锤头重量及柄材质不同 |
| 铁锤 | 锤子、圆头锤（泛称） | 把、把/支 | 锤型多种，不把泛称当具体款 |
| 橡胶锤 | 橡皮锤 | 把、把/支 | 锤头硬度、黑白胶不同 |
| 手锯 | 钢锯、钢锯架（易混） | 把、架 | 锯架与锯条分开识别 |
| 钢锯条 | 锯条 | 片、支、盒 | 长度、齿数、材质需核 |
| 木工锯 | 手锯、板锯 | 把、支 | 与钢锯用途和锯齿不同 |
| 锉刀 | 锉、什锦锉（细分类） | 把、支、套 | 形状、齿纹、长度不同 |
| 卷尺 | 钢卷尺、皮尺（易混） | 把、个 | 钢卷尺与软尺不是同物 |
| 水平尺 | 水平尺子 | 把、支 | 长度和精度等级不同 |
| 游标卡尺 | 卡尺（泛称） | 把、支 | 数显/带表/游标款不同 |
| 美工刀 | 壁纸刀、裁纸刀（口语） | 把、支 | 刀片是否随附要核对 |
| 美工刀片 | 壁纸刀片、刀片（泛称） | 片、盒、包 | 刀型、宽度不同 |
| 剪刀 | 铁皮剪（特定类型）、剪子（泛称） | 把、把/支 | 家用剪与铁皮剪不可混 |
| 撬棍 | 起钉撬棍、撬杠 | 根、支 | 长度、头型不同 |
| 砂纸架 | 打磨板、砂纸夹 | 个、把 | 与砂纸耗材分开 |
| 钢丝刷 | 钢丝刷子、手刷 | 把、个 | 刷丝材质、排数不同 |
| 油灰刀 | 批刀、刮刀（泛称） | 把、支 | 宽度和刀片弹性不同 |

工具类别依据：[中国五金制品协会产品类别](https://www.chinahardware.org.cn/single-data.jsp?mid=14)。
