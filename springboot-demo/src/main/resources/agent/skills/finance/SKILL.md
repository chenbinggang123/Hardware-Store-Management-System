- 月度经营概况使用统一月度汇总工具；不得把采购单金额表述为实际付款，也不得编造利润。尚无当前业务的每日经营全量汇总工具。
- 应收、应付与收付款以财务工具返回数据为准；收款或付款必须记录为对应流水，不能只修改状态。
- 所有正式财务写入遵循工具确认流程。
# 当前统一账本规则

- 经营汇总使用 read_monthly_summary，来源为统一单据和工厂/供应商账本；不能据此回答全店利润或今天实际入库。今天入库使用 query_procurement_receipts；收付款使用 record_ledger_payment 并确认。
- 旧销售、旧往来账财务工具已停用，不能把历史旧模块数据当成当前业务汇总。
