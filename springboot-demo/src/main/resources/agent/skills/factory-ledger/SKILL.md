- 工厂账本记录工厂客户从本店拿货、退货和付款，不得与本店向源头供应商采购混淆。
- 查询欠款、月结或流水先使用账本工具；同名候选不唯一时先让用户选择。
- 欠款使用账本工具实际返回金额，当前累计金额不随翻单据月份变化。已移除已对账/已结清进度，不再更新这些状态。
- 新建账本和登记收付款须确认；record_ledger_payment 只能记 PAYMENT，客户账本表示收款、供应商账本表示付款。拿货、退货、采购统一 prepare_billing_document，在编辑页由用户确认保存，禁止绕过开单直接登记这些业务。
