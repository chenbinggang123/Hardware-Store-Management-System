# 微信小程序前端说明

## 目录
- 小程序项目目录：`miniprogram`
- 默认生产后端地址：`https://api.hardware1122.xin/api`

## 打开方式
1. 打开微信开发者工具。
2. 选择导入项目。
3. 项目目录指向当前仓库下的 `miniprogram`。
4. 开发调试阶段可以勾选“不校验合法域名、web-view（业务域名）、TLS 版本以及 HTTPS 证书”。
5. 真机预览和发布前，需要在微信公众平台配置服务器域名：`https://api.hardware1122.xin`。

## 当前页面结构
- 登录页
- 首页
- 商品管理：列表、详情、表单
- 供应商管理：列表、详情、表单
- 客户管理：列表、详情、表单
- 进货管理：列表、详情、表单
- 销售管理：列表、详情、表单
- 库存管理：列表、详情、盘点调整
- 报表中心、报表导出
- 系统设置、用户管理、操作日志

## 说明
- 当前小程序优先服务开发联调和页面验收。
- 当本地后端不可用时，会自动使用内置模拟数据，方便直接查看界面效果。
