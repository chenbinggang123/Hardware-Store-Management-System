# 微信小程序前端说明

> 2026-10-29 更新：五金店业务、附件、图片与 Excel 均连接自有云服务器。CloudBase 不再是小程序运行依赖；用户取消历史数据迁移，从空业务库开始。

## 当前常用入口

- 小五对话与生成文件、快捷开单、开单记录、工厂账本、商品（含库存）、进货和文件。
- 工厂账本提供“月度汇总”入口。旧销售单列表、详情、编辑页已移除；设置不再重复提供单据记录或汇总入口，保留往来账、联系人、价格历史、批量导入、用户与日志。
- 工厂账本支持资料编辑与流水冲销；快捷开单确认后可记入账本，已记账单据作废时同步冲销。
- 商品页面取消上下架入口；未建立库存记录显示“未记录”，盘点前可确保创建记录。
- 旧页面仍保留，完整页面注册以 `app.json` 为准。原模拟备份与恢复入口已移除。

## 目录
- 小程序项目目录：`miniprogram`
- 默认后端：`https://hardware.plain-cookie.com/api`。配置文件为 `config/cloud.js`（仅保留历史文件名）。

## 打开方式
1. 打开微信开发者工具。
2. 选择导入项目。
3. 项目目录指向当前仓库下的 `miniprogram`。
4. 保持合法域名校验开启；微信后台的 request 与 uploadFile 合法域名均应包含 `https://hardware.plain-cookie.com`。
5. 普通接口使用 `wx.request`，文件上传使用 `wx.uploadFile`。图片由带 Bearer 的请求读取后写入本机临时文件，不公开存储目录。
6. 重新编译、预览验收后再上传发布；已发布旧代码不会随本地修改自动更新。

## 说明
- 当前小程序优先服务开发联调和页面验收。
- 当前业务请求不再回退到内置模拟数据；服务器请求失败时应提示失败。非登录接口返回 401 时清理会话并回到登录页。
