# 微信小程序前端说明

> 2026-10-21 更新：当前功能与接口以 [当前实现与前后端修正说明](../docs/当前实现与前后端修正说明.md) 为准。小程序普通请求始终调用配置的云托管服务，启动本地后端不会自动切换请求目标。

## 当前常用入口

- 小五对话与生成文件、快捷开单、开单记录、工厂账本、商品（含库存）、进货和文件。
- 工厂账本提供“月度汇总”入口。旧销售单列表、详情、编辑页已移除；设置不再重复提供单据记录或汇总入口，保留往来账、联系人、价格历史、批量导入、用户与日志。
- 工厂账本支持资料编辑与流水冲销；快捷开单确认后可记入账本，已记账单据作废时同步冲销。
- 商品页面取消上下架入口；未建立库存记录显示“未记录”，盘点前可确保创建记录。
- 旧页面仍保留，完整页面注册以 `app.json` 为准。原模拟备份与恢复入口已移除。

## 目录
- 小程序项目目录：`miniprogram`
- 默认后端：CloudBase 环境 `cloud1-d0gvllpf639d10665` 中的云托管服务 `hardware-store-api`

## 打开方式
1. 打开微信开发者工具。
2. 选择导入项目。
3. 项目目录指向当前仓库下的 `miniprogram`。
4. 开发调试阶段可以勾选“不校验合法域名、web-view（业务域名）、TLS 版本以及 HTTPS 证书”。
5. 真机预览和发布前，确认小程序已关联该 CloudBase 环境；普通接口使用 `wx.cloud.callContainer`，附件使用 `wx.cloud.uploadFile`，无需配置旧的自定义域名。

## 当前页面结构
- 登录页
- 首页
- 商品管理：列表、详情、表单
- 供应商管理：列表、详情、表单
- 客户管理：列表、详情、表单
- 进货管理：列表、详情、表单
- 销售管理：列表、详情、表单
- 库存管理：列表、详情、盘点调整
- 报表中心、报表导出
- 系统设置、用户管理、操作日志

## 说明
- 当前小程序优先服务开发联调和页面验收。
- 当前业务请求不再回退到内置模拟数据；云环境未配置或请求失败时应提示失败。非登录接口返回 401 时清理会话并回到登录页。
